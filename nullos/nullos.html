NullØS

Minimal by design. Controlled by you.

A lightweight Linux distribution for security work. It runs on Ubuntu 24.04 with a keyboard-driven tiling desktop, and keeps the controls that matter in one Security Center.

Download the ISO Try the Security Center
Run in a terminal:

Working preview of the desktop. Move your mouse over the desktop and press Enter, E, Q, V, F, H, L or 1 to 4, or hold Alt (or Super) with a key while typing in a terminal. Esc leaves the terminal, and pressing Enter on an empty prompt opens another one. If nothing reacts, click the desktop once so the page has keyboard focus. The buttons do the same. Everything here is simulated and runs in your browser.

Four decisions behind the system

NullØS uses established Linux parts and adds its own desktop setup, management tools and security controls. It does not ship a custom kernel.

Minimalism

A focused desktop without clutter. The base install holds the essentials and you add the rest when you need it.

Control

Keyboard shortcuts, two desktop modes, themes and system controls that you can change.

Security

AppArmor, nftables, sandboxing, audits and the Security Center come set up together.

Transparency

The source and the build process are public. Security features are meant to be documented and checkable.

Tile it, or float it

The default desktop is i3. Windows arrange themselves, and nearly everything is a shortcut. Prefer title bars and overlapping windows? Switch to Openbox with one command.

i3 tiling desktop (default)

  • Windows tile automatically, with gaps and borders you can change
  • Multiple workspaces, tabbed and split layouts, fullscreen
  • Floating windows and a scratchpad
  • F12 drops a terminal from the top of the screen

Openbox floating desktop

  • Conventional title bars
  • Freely movable, resizable, overlapping windows
  • Mouse-driven, familiar interaction
ns-mode tiling
ns-mode floating

Keyboard shortcuts

Super is the Windows key on a PC keyboard. Alt works for the core shortcuts if your virtual machine keeps Super for itself. Super + left-drag moves a floating window and Super + right-drag resizes it.

One accent, your choice

Pick red, blue, green or black and white. ns-theme recolours the panel, window borders, menus, terminal, GTK apps, shell prompt and the Fastfetch and Neofetch logo together. This page follows your choice too.

One place for security controls

The Security Center arrived in NullØS 2.0 and opens with Super + S. It brings profiles, status, audits, logs and the emergency disconnect together. Its status checks the running system and does not trust a config file.

        AppArmor

        Mandatory access control that limits what applications and processes can touch. Profiles run in enforcing or complain mode, and the Security Center reports complain-mode profiles separately from real failures. The protection you get depends on the profiles that are loaded and enforced.

        ns-secure status

        nftables

        The firewall framework. NullØS ships a ruleset that blocks inbound traffic by default. Read the active rules before you depend on them, because enforcement is only as good as what is loaded.

        sudo nft list ruleset

        Sandbox

        Run an application inside a bubblewrap sandbox with limited access to files and the host. A sandbox narrows what a program can reach. It is not a virtual machine, and its strength depends on how you configure it.

        ns-sandbox

        Research labs

        Build isolated network environments from namespaces and bridges for testing and experiments. Release 2.0.1 clears stale bridges and namespaces after a failed attempt. Test the isolation yourself before you trust it.

        ns-lab

        Audits

        Five categories: credentials, privileges, services, users and packages. What each check covers is defined by the audit implementation, so read docs/SECURITY.md for specifics.

        ns-secure audit

        Tool management

        Keep the install lean and add tools when you need them. Installs wait for apt and dpkg locks, so a background update does not break them. Prowler and ScoutSuite cover cloud security work.

        ns-pack add nuclei

        The tools you reach for daily

        NullØS installs 30+ core tools and leaves the heavy ones out. Large packages and tools from outside Ubuntu install on request, so the ISO stays small.

        Commands that feel like home

        Standard Linux tools are all there, along with a family of ns- commands for the desktop, security and system. Copy any of them.

        The terminal setup is XFCE Terminal with zsh and tmux. Also installed: ifconfig, ip, ping, ssh, dig, whois, htop, tree, nano, unzip, lspci, lsusb, man, neofetch and fastfetch.

        Plain about its limits

        A security-focused system should say what it does not promise.

        • It is not a new Linux kernel.
        • It does not replace every general-purpose distribution.
        • It does not guarantee complete system security.
        • It does not guarantee anonymity or that you cannot be traced.
        • It does not make every application safe.
        • Sandboxing is not the same as virtual machine isolation.
        • It does not remove the need for updates, maintenance and testing.

        arm64

        Verify and boot

        1. Download the ISO for your architecture from the release page.
        2. Hash it and compare the result with the checksum published next to the file. sha256sum nullos-arm64-v0.1.0.iso
        3. Write it to a USB stick, or attach it to a virtual machine.
        4. Boot the live desktop. To install, open Start menu, then Install NullØS.

        Good to know

        • The live login is ns with no password and passwordless sudo. The installer keeps the live auto-login and sudo rule out of the installed system.
        • In a virtual machine, give it 4 GB of RAM and 2 or more cores.
        • No sound in UTM? Add an Intel HDA sound device, then run ns-audio fix.
        • Test the installer on your own hardware and disk layout before you rely on it.

        Questions

        Short answers about what NullØS is and what it is not.

        Is NullØS based on Kali or Parrot?

        No. It is built on Ubuntu 24.04 and uses the official Ubuntu kernel. The tool selection is its own, and tools that Ubuntu does not package install on request with ns-pack.

        Why a tiling desktop and not Hyprland?

        Hyprland needs GPU-accelerated Wayland, which most virtual machines do not have. NullØS uses i3 with automatic tiling and gaps, so it behaves the same on real hardware and in a VM.

        Does it make me anonymous?

        No. NullØS does not promise anonymity or that you cannot be traced. It includes tools such as WireGuard, OpenVPN, proxychains and macchanger, and what they protect depends on how you set them up.

        Can I install it to disk?

        Yes. Since 2.0.2 the live desktop includes a Calamares installer. Open the Start menu and choose Install NullØS. It supports offline installation on UEFI and BIOS systems.

        Does it work in a virtual machine?

        Yes, and VMs are a main target. Guest tools for UTM, VirtualBox, VMware and QEMU are included, so the clipboard, resizing and mouse behave.

        What does the Security Center check?

        It checks the state of the running system, such as the relevant service and firewall, and does not report a protection as active only because a configuration file exists. What each profile and audit covers is written in docs/SECURITY.md.

        How do I report a problem?

        Run ns-diag. It writes a report to ~/nullsec-diag.txt. Read it before you share it, because it can contain private system or network details, then open an issue in the GitHub repository.

        Is it legal to use?

        Using it is. Attacking systems you do not own or have no permission to test is not. Test only systems you own or have written permission to test.
