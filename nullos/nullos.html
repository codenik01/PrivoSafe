Built to stay out of your way

  
Most security distros ship thousands of tools and a desktop that looks like an office PC. NullØS ships the ones you reach for daily and looks like a workstation.

  

   
Tiling desktop
Windows tile themselves with gaps and accent borders. F12 drops a terminal from the top. Prefer title bars? Switch to floating mode with one command.

   
Hardened defaults
Inbound traffic is blocked by default, Wi‑Fi MAC addresses are randomised, kernel hardening is on, and unused services (Bluetooth, printing, discovery) are off.

   
Lean toolset
nmap, masscan, ffuf, gobuster, sqlmap, hydra, john, aircrack‑ng, bettercap, radare2, gdb, pwntools, impacket and more are already installed. Heavier tools install when you ask.

   
One accent, your choice
Red, blue or green. ns-theme blue recolours the panel, borders, menus, terminal, GTK apps, prompt and logo together.

   
Made for VMs
Guest tools for UTM, VirtualBox, VMware and QEMU are included, so clipboard, resizing and mouse behave.

   
Ordinary apps, done
Files, text editor, Wi‑Fi menu, audio mixer, archive manager, screenshots, PDF and image viewers, calculator and Firefox. Right‑click in the terminal gives you Copy and Paste.

   
x86_64 and arm64
Built natively for both, including Apple silicon through UTM.

Commands that feel like home

   
Standard tools are all there, plus a few of ours.

Download

  
NullØS runs live from the ISO today. An installer is not included yet, so use it from a USB stick or a VM.

  

   
x86_64
Intel and AMD. Boots on BIOS and UEFI.

   Get nullos-amd64.iso
  

  

   
arm64
Apple silicon through UTM, and other UEFI arm64 machines. Newer and less tested than x86_64.

   Get nullos-arm64.iso
  

  
Check the download before you boot it, then compare the result with the checksum published next to the file:

  
sha256sum nullos-amd64.iso

  
Live login is ns with no password and passwordless sudo. In a VM, give it 4 GB of RAM and 2 or more cores.

 


 

  
Questions

  

  
Is NullØS based on Kali or Parrot?
No. It is built on Ubuntu 24.04 and uses Ubuntu’s kernel. The tool selection is its own, and tools Ubuntu does not package install on demand with ns-pack.

  
Why a tiling desktop and not Hyprland?
Hyprland needs GPU‑accelerated Wayland, which most VMs do not have. NullØS uses i3 with automatic tiling, gaps and animations so it behaves the same on real hardware and in a VM.

  
Does it work in a virtual machine?
Yes. That is the main target. UTM, VirtualBox, VMware and QEMU are covered by the included guest tools.

  
Can I install it to disk?
Not yet. The ISO is a live system. Use it from USB or inside a VM.

  
Is it legal to use?
Using it is, but attacking systems you do not own is not. Test only systems you own or have written permission to test.
